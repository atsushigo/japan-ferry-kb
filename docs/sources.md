## 方法備註

- 官方頁面由平行 agent 讀取，每個 agent 回報讀取的網址、取得內容與未取得項目。
- PDF 文字層失敗者轉成圖片，票價表放大逐格核對。
- **抓取工具的限制**：它回傳的是頁面「摘要後的畫面文字」。釜山 FAQ 的答案嵌在頁面原始碼的資料區塊（展開前不顯示），agent 回報「只有標題」，直接下載原始 HTML 後才取得 62 題的完整答案。
- 所有價格與時刻都是**公布當時的資料**，不是即時資料。
