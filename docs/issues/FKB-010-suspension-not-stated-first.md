# FKB-010：問上海票價時，航線客運暫停的狀態被放在回答最後，且沒說明目前不能購買

| Field | Value |
|---|---|
| Type / Priority / Status | Bug / High / Open |
| Component | chatbot-prompt |
| Found in | chat-001 A10、提示詞 v2、gemini-3.5-flash-lite |
| Reported | 2026-11-21 JST |
| Related | `knowledge/kansai-shanghai-shinganjin.md` |

## Description
知識庫記載上海航線客運暫停（2025-12-08 公告，重啟時間未定）。問「上海航線的票價是多少人民幣？」時：

| 重複 | 暫停狀態出現的位置 | 說明目前不能購買 |
|---|---|---|
| #1 | 第 345 字（共 491 字，注意事項最後一行） | 否 |
| #2 | 第 445 字（共 660 字，最後的註） | 否 |
| #3 | 第 14 字（開頭） | 否 |

規則 3 要求「先說明這個狀態，再回答細節」，3 次中只有 1 次做到；且沒有任何一次說明暫停期間不能購買。相比之下，A2 直接問「現在有開嗎」時 3/3 都先說明暫停。使用者只看前幾行就可能以為可以訂票。

## Root cause（Suspected）
票價問題的重點被模型放在價格表，狀態被當成附註。規則 3 只說「先說明」，沒有指明「回答任何與此航線有關的問題都要先說」，也沒有要求註明「暫停期間不能購買」。

## Resolution（提案，未驗證）
1. 規則 3 改為：「只要問題與上海航線有關（票價、班次、行李等），回答的第一句必須先說明客運暫停、重啟時間未定，以及暫停期間不能購買船票，再回答細節。」
2. 評估在知識庫的上海票價段落標題直接加註「（客運暫停期間不可購買）」，讓檢索到的段落自己帶著這個狀態。

## Verification
A10 重跑 10 次，暫停狀態必須都出現在前兩句內；`score_chat.py` 尚無此檢查，需新增「位置檢查」。

## Lessons learned
同一條規則在直接問狀態（A2）與間接問票價（A10）下遵守度不同，測試題要涵蓋間接情境。
